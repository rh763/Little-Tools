How it works

Random seed points are scattered inside the solid and split space into Voronoi cells. Every cell edge becomes a round strut, and the cells are cut by the outer surface, which adds a cage of struts on the outside.

Min cell size keeps seed points at least this far apart, so every cell holds a sphere of that diameter. Use it to stop small cells from fusing shut when printed. If the requested number of cells does not fit, fewer cells are placed.

Min strut length collapses struts shorter than this into a single node. Seed spacing alone cannot stop cells from having a few very short edges, so this is the setting that removes tight node clusters.

Relaxation nudges the cells toward equal size. 0 is fully random.

Node fillet blends struts into each other at the nodes. It is a percentage of the strut thickness. The live preview approximates the fillet shape; the mesh is exact.

Every setting has a ? button next to it with a short explanation.

Mesh resolution is the voxel size used to build the triangle mesh. The live mesh preview uses a coarser grid when needed. Process mesh builds it at the chosen resolution, ready to download.
